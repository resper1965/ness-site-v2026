## As perguntas que o time precisa responder

1. **Quem são os públicos?** (colaboradores em geral, TI, liderança, quem trata
   dado pessoal, terceiros?)
2. **Como o conteúdo chega?** Trilhas por público, módulos avulsos, campanhas?
3. **O que fica de evidência de conclusão?** É isso que transforma o produto em
   prova para o controle A.6.3 da ISO 27001 e para o programa de privacidade —
   e é o coração do momento marcante.
4. **O conteúdo é nosso, do cliente, ou os dois?** Dá para o cliente subir o
   dele?
5. **Tem avaliação?** Nota, tentativa, reprovação, reciclagem periódica?
6. **Simulação de phishing entra?** (é o que o mercado espera de uma plataforma
   assim; se não entra, dizer que não entra vale mais do que silêncio)
7. **Como o gestor acompanha?** Quem fez, quem falta, o que vence.
8. **O que fica fora do escopo?**
